Cómo funciona la proyección
Primero calculamos la posición relativa:

let offset_x =
    sprite.x - player.pos.x;

let offset_y =
    sprite.y - player.pos.y;


Después obtenemos:

distancia al sprite
ángulo absoluto del sprite
ángulo relativo a la cámara


El ángulo relativo se normaliza entre:

-π y π


para que no exista un salto cuando la rotación cruza de 359° a 0°.

Si el sprite está fuera del campo de visión:

if relative_angle.abs()
    > FOV / 2.0
{
    return;
}


no dibujamos nada.

Corrección de profundidad
Usamos:

    distance
        * relative_angle.cos();

Esto coloca el sprite en el mismo espacio de profundidad que las paredes guardadas en `depth_buffer`.

Luego, por cada columna:

}
